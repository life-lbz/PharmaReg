# PharmaReg 业务垂直相似场景与企业整合分析（国内企业版）

> 文档性质：行业对标研究（Markdown / GFM）
> 编制时间：2026-09-07
> 研究对象：PharmaReg —— 面向制药企业的 GxP 质量合规数字化平台（GMP 生产质量 + GCP 临床/药物警戒双域，含 AI 法规问答）
> 分析方法：以项目代码库所还原的企业业务原型为基线，拆解垂直业务场景，检索并分层整合国内（含大中小各规模）具有垂直相似业务的企业
> 范围说明：本版仅收录中国本土企业；外资在华产品线（如 Oracle Argus、Veeva、Medidata 在华业务）仅作为竞争背景一笔带过，不展开

## 1. 执行摘要

PharmaReg 的业务原型是一家同时开展药品生产（GMP）与药物临床试验（GCP）的综合型制药企业，覆盖偏差、变更、CAPA、批放行、培训认证、审计准备、SAE/药物警戒、法规条款知识库与 AI 问答等完整 GxP 流程，以电子签名、防篡改审计日志、角色权限矩阵作为数据完整性底座。

国内与该业务存在垂直相似度的企业可按规模与域划分为五类：

1. **多域平台型（头部及平台级）**：太美医疗科技（临床 + 药物警戒，多产品线）、重庆阿克索（GMP 质量系统全套）、易迪希（临床数字化产品家族）、百奥知（临床 + 真实世界研究一体化）。
2. **GMP 质量数字化厂商**：彩蝶软件、飞企耀点、辛格迪、洛施德 SISQP（+ 平台级的阿克索）。
3. **临床研究与注册数字化厂商**：一临云、微试云、明度智云、柯里特、宝信软件（+ 平台级的太美、易迪希、百奥知）。
4. **药物警戒厂商**：太美 eSafety、易迪希 Clinflash Safety，另有行业报告提及的科临达康、通和立泰、翊科等（信息源强度较低，见第 8 节）。
5. **法规数据与 AI 服务商**：医药魔方、药智、药融云（摩熵医药）。

本报告的核心判断：**国内市场的结构性特征是"单域集群、双域断层、AI 原生合规空白"**——没有一家本土厂商同时完整打通 GMP 生产质量与 GCP 临床/药物警戒两域，且将 AI（RAG 问答 + Agent）作为合规流程的原生能力；而国家药监局 2026 年《"人工智能+药品监管"实施意见》明确将大模型定位为辅助应用并要求场景化合规审查 [cite:26]，为该类产品的落地提供了政策窗口。

## 2. 项目业务原型与垂直域基线

以下基线基于项目代码库（27 张业务表、11 类岗位角色、10 个业务 Agent、状态机与权限矩阵）归纳，作为对标参照。

### 2.1 组织与角色原型

| 业务域 | 角色 | 对应真实企业部门/岗位 |
|---|---|---|
| GMP 生产 | operator、qc、qa、engineer | 生产车间操作工、QC 检验员、QA（含质量受权人）、设备工程师 |
| GCP 临床 | investigator、crc、cra | 研究者（PI/副研究者）、机构 CRC、申办方 CRA |
| 药物警戒 | pv | 药物警戒（PV）部门 |
| 通用支撑 | trainer、compliance | 培训中心、内审与法规事务部门 |
| 系统 | admin | 系统管理员 |

### 2.2 业务能力模块清单（M 编号，供第 6 节矩阵引用）

| 编号 | 能力模块 | 业务内涵 |
|---|---|---|
| M1 | 偏差管理 | 上报 → 分级 → 调查 → QA 审核 → 关联 CAPA → 关闭（关闭前置 CAPA 已验证） |
| M2 | 变更控制 | 发起 → 影响评估 → 审批 → 实施（四眼原则） |
| M3 | CAPA | 联动偏差/变更、有效性检查 |
| M4 | 批扣留与放行 | 问题批扣留、质量受权人放行 |
| M5 | 培训与认证 | 岗位培训矩阵、题库/考试/证书 |
| M6 | 法规条款知识库 | GMP/GCP 规章条款化、版本对比、FAQ 审批 |
| M7 | 审计准备 | 内审/迎检清单、证据、差距项 |
| M8 | SAE/药物警戒 | SAE 记录 → PV 审查 → 研究者签署 → 时限上报 |
| M9 | GCP 临床研究流程 | 受试者/研究者/CRA/CRC 协作 |
| M10 | 合规底座 | 电子签名、防篡改审计日志、权限矩阵 |
| M11 | AI 法规问答 | RAG 检索、幻觉校验、人工复核、多 Agent 编排 |
| M12 | 系统与多租户 | 用户/角色/权限、租户隔离、操作审计 |

## 3. 垂直相似场景画像

| 场景 | 描述 | 代表业务动作 |
|---|---|---|
| S1 药品生产质量数字化 | QMS 管理偏差、变更、CAPA、培训、文件，满足 GMP 与数据完整性 | 偏差闭环、电子签名、审计追踪 |
| S2 临床研究信息化 | EDC/CTMS 支撑临床试验，满足 ICH GCP | 受试者数据、监查、稽查准备 |
| S3 药物警戒与安全性报告 | SAE/不良事件收集、评估、时限上报 | 病例管理、E2B 上报 |
| S4 法规情报与知识问答 | 法规条款结构化、检索与对话问答 | 条款知识库、RAG 问答 |
| S5 GxP 合规底座服务 | 电子记录/签名、审计日志与验证 | 21 CFR Part 11、EU Annex 11、GAMP 5 |

国内企业大多只覆盖 S1-S4 中的一到两个场景，无单平台全覆盖者。

## 7. 国内竞争格局与企业整合分析

### 7.1 竞争结构

**临床数字化赛道（S2/S3）头部集中，中小并存。** 太美医疗处于第一梯队，产品线从临床研究延伸至药物警戒与机构端 GCP-X 平台 [cite:1][cite:3]；百奥知、一临云、易迪希、微试云等构成二线，各自以低代码平台、AI 预测、产品家族完整性或机构网络差异化竞争 [cite:7][cite:9][cite:12][cite:11]。

**GMP 质量赛道（S1/S5）国产替代加速。** 阿克索以"让中国药企用上国际品质的质量管理系统"定位，直接对标国际 QMS 并已获齐鲁、华海等头部客户 [cite:6]；辛格迪以恒瑞、上药等客户群覆盖大型与生物科技药企 [cite:16]；彩蝶深耕疫苗等细分制造场景 [cite:14]；飞企耀点、洛施德服务区域与中型药企 [cite:15][cite:18]。该赛道竞争焦点是"是否真正理解中国 GMP 检查口径 + 国际标准（GAMP5/cGMP）的融合"。

**注册申报数字化（S4 注册侧）政策驱动增长。** 国家药监局推进 eCTD 实施带动明度智云、柯里特等厂商，宝信软件作为药监系统建设方占据特殊地位 [cite:23][cite:24][cite:25]。

**外资背景说明。** 在临床/PV 高端市场，Oracle（Argus）、Medidata、IQVIA、Veeva 等外资产品仍占据跨国药企在华客户，国内厂商主要服务本土 MAH；本报告聚焦本土企业，不展开外资竞争细节。

### 7.2 竞合关系总览

| 关系类型 | 涉及企业 | 说明 |
|---|---|---|
| 直接竞争（同域同层） | 阿克索/辛格迪/彩蝶/耀点/洛施德（S1）；太美/易迪希/百奥知/一临云/微试云（S2/S3 部分） | 同一垂直域争夺同类药企客户 |
| 形态互补（流程系统 × 数据服务） | PharmaReg × 医药魔方/药智/药融云 | 外部法规/药品数据可作为企业内部知识库的内容源 [cite:19][cite:20][cite:21] |
| 政策同向（AI+监管） | 全体厂商 | 药监局将 AI 定位为辅助应用、要求场景化合规审查 [cite:26]，利好"AI 辅助 + 人工担责"类产品叙事 |
| 潜在追赶（单域厂商上探） | 太美、阿克索、易迪希、百奥知 | 均具备向相邻域扩展的产品与技术基础，是 PharmaReg 定位的最大不确定性来源 |

### 7.3 差异化定位分析（对 PharmaReg 类产品的启示）

1. **双域断层即机会。** 国内没有单平台同时覆盖 M1-M9；若 PharmaReg 贯通"GMP 质量（M1-M7）+ GCP/PV（M8-M9）"，将形成"研发-生产全生命周期质量"的唯一本土样本，与太美（GCP 侧）、阿克索（GMP 侧）的单域纵深正面错位。
2. **AI 原生合规问答是时间窗口。** M11 在国内完全空白；结合药监局"辅助型定位 + 功能边界 + 责任主体"的监管口径 [cite:26]，条款级引用、幻觉阻断与人工复核的"人机协同"设计可同时满足监管叙事与工程差异化。
3. **合规底座（M10）是入场券而非护城河。** 电子签名、审计追踪是阿克索、太美等所有国产厂商的标配卖点 [cite:4][cite:1]；PharmaReg 需在验证文档（GAMP5/CSV 对齐）与工程成熟度上补齐，才能进入商用候选序列。
4. **数据层可借力而非自建。** 医药魔方/药智/药融云已有成熟的药品与法规数据体系 [cite:19][cite:20][cite:21]，企业内知识库可采用"条款内容自建 + 外部数据订阅"的混合策略，降低 M6 的构建成本。

## 8. 局限与未验证项

1. 企业信息主要来自各厂商官网与 2026 年公开资料；模块覆盖矩阵基于公开产品线推断，未经产品实测。
2. 第 4.4 节科临达康、通和立泰、上海翊科等 PV 厂商信息源自二手商业报告（豆丁网市场分析报告）[cite:27]，市场份额等数字可信度低，本报告未采用任何份额数据，仅作方向性线索。
3. 宝信软件、明度智云、柯里特等厂商的完整产品矩阵未逐层核实，可能遗漏其质量/合规类产品。
4. 上市公司/融资规模等商业指标未纳入量化对比（缺乏统一口径公开数据），规模判断为方向性表述。
5. 国家药监局《"人工智能+药品监管"实施意见》通过上海市药品监督管理局官网转载获取 [cite:26]，各地执行细则与落地时间未跟踪。
